Customer Call-Time Optimization Dashboard

2022

Designed a dynamic Google Sheets dashboard at Quill that monitors real-time call duration in 15-minute segments and recalculates the pace needed to hit the daily talk-time goal. Using it raised my daily talk time from the 3 hr 45 min minimum to ~5 hours, a 33% increase.

  • Google Sheets
  • Dashboard design
View Dashboard Get Your Own Copy
How to use this dashboard
  1. Make your own copy of the sheet, then duplicate the "Call Time Planner" tab. Do all of your daily edits on the Copy of Call Time Planner tab — this keeps the original tab clean and makes resetting for the next day easy.
  2. If your shift starts at a different time, edit cell G2 under the TOD column.
  3. Set your goal in cell O8 — clicking it reveals a dropdown. Selecting 3:45:00 sets an average call-time target of 0:08:02 per 15-minute segment; selecting 4:30:00 raises that target to 0:09:39.
  4. If you're participating in a Flex Time program (working a bit extra Mon–Thu to leave early on Friday), add Flex Time starting with the first item in the list, adding more as your policy permits. Each addition lowers your required goal per 15-minute segment.
  5. If you're leaving early, start unchecking the L column from the bottom. Also make sure no Flex Time is checked.
  6. Block out breaks, lunch, and meetings — those segments highlight in yellow to mark their start and end.
  7. Throughout the day, once a 15-minute segment is complete, edit that row's Adjusted cell with your actual call time. Delete the existing contents and type your time with no equals sign, in 00:00:00 format (e.g. 00:05:00). The next row automatically recalculates the call-time goal needed to stay on track.
